# Molecular Geometry Calculator

A Python program that performs molecular geometry calculations using crystallographic coordinate files.

## Features

- Bond Length Calculation
- Bond Angle Calculation
- Torsional (Dihedral) Angle Calculation
- Least Squares Line Calculation
- Fractional to Cartesian Coordinate Conversion

## Requirements

- Python 3.x
- NumPy

## Project Files

- `geometry_calculator.py` – Main program
- `atomcols.def` – Atomic radii data
- `sample_coordinate_file.txt` – Input coordinate file
